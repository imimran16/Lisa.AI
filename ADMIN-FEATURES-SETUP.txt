LISA AI — ADMIN DOWNLOADS, RATING & PUSH SETUP

1. Open Supabase Dashboard > SQL Editor > New query.
2. Open SUPABASE-ADMIN-FEATURES.sql from this ZIP, copy the ENTIRE file, paste it into SQL Editor and press Run.
   This creates lisa_download_events, lisa_app_settings and lisa_push_subscriptions, grants the server role access, and reloads the API schema cache.
3. In Vercel > Project > Settings > Environment Variables, confirm:
   SUPABASE_URL
   SUPABASE_SECRET_KEY (or SUPABASE_SERVICE_ROLE_KEY)
   VAPID_PUBLIC_KEY
   VAPID_PRIVATE_KEY
   VAPID_SUBJECT = your-email@gmail.com (plain email is accepted; server adds mailto:)
   Never share or publish VAPID_PRIVATE_KEY or the Supabase secret/service-role key.
4. Redeploy the Vercel project after the SQL and environment variable checks.
5. Open /admin.html. The App downloads & rating section shows four separate cards:
   - Original APK downloads: successful APK download requests counted by /api/download.
   - Website Downloaders count: public number editable and saved by the admin.
   - Overall app rating.
   - Total reviews.
   Original APK downloads count requests, not unique people or confirmed installs.
6. Push notifications can be sent only to devices that opened Lisa and opted in to notifications.
7. The public website shows the saved Website Downloaders count and rating/review summary under the app download area. The notification opt-in is in the side menu.
