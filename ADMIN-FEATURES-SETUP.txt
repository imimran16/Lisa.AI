LISA ADMIN — DOWNLOAD COUNTS AND PUSH NOTIFICATIONS

1. In Supabase Dashboard, open SQL Editor and run the complete file:
   SUPABASE-ADMIN-FEATURES.sql
   This creates lisa_download_events, lisa_app_settings and lisa_push_subscriptions.

2. Confirm Vercel has SUPABASE_URL and SUPABASE_SECRET_KEY (or
   SUPABASE_SERVICE_ROLE_KEY) set, then redeploy.

3. Admin > App downloads & rating shows:
   - Original APK downloads: number of successful APK download requests recorded
     by /api/download. This is not a count of unique people or installs.
   - Website Downloaders count: the separate number you can edit and save.
   The public website displays the saved Downloaders number plus average rating
   and review count below the Download Android App button.

4. Push notification opt-in has been moved into the website side menu so it is
   no longer displayed below the download button. The Admin send form stays in
   /admin.html.

5. Set VAPID_SUBJECT in Vercel to your plain email address, for example:
   mdimranahamad732@gmail.com
   The server automatically converts it to mailto: and repairs a common milto:
   typo. Never share VAPID_PRIVATE_KEY publicly.

6. Redeploy after updating files or environment variables.
